Panduan Desain Website Desa Haria

Tema Warna (Biru - Putih - Kuning)

Palet warna ini melambangkan laut/pesisir (Biru), kebersihan/kedamaian (Putih), dan matahari/harapan/energi (Kuning).

Primary Color (Biru): #00529B (Digunakan untuk Navbar, Footer, Tombol Utama, Header Section)

Secondary Color (Kuning): #FFD100 (Digunakan untuk aksen, tombol hover, highlight teks, icon)

Background (Putih/Abu Terang): #FFFFFF untuk area konten utama, #F8FAFC untuk background section selang-seling.

Text Color: #1E293B (Slate-800) untuk teks utama, #64748B untuk teks sekunder.

Komponen UI

Hero Section: Foto panorama pesisir/desa Haria dengan overlay gradient gelap. Teks sambutan besar dan tombol CTA (Call to Action) warna Kuning ("Jelajahi Desa" & "Lapor/Saran").

Card UI: Gunakan sudut melengkung (rounded-xl), bayangan lembut (shadow-md). Digunakan untuk entitas: Wisata, UMKM, Berita.

Tipografi:

Heading: Font Serif yang elegan (misal: Merriweather atau Playfair Display) untuk kesan tradisional/bersejarah.

Body: Font Sans-serif yang mudah dibaca (misal: Inter atau Roboto).

Form Pengaduan: UI bergaya chat atau modal simpel dengan tombol "Masuk dengan Google" yang mencolok. Area drag-and-drop untuk maksimal 5 foto.
